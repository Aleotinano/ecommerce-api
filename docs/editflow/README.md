# EditFlow

El software de gestión para la agencia de video vive en su propio proyecto:
`Aleotinano/editflow-api` y `Aleotinano/editflow-client`. Su documentación —revisión del
estado actual, arquitectura, dominio, qué se reutiliza de Cori y el plan por fases— está en
`docs/` de `editflow-api`.

Esta carpeta tenía un kit para arrancarlo desde cero; quedó superado al revisar el código que
ya existía. Sigue en el historial de git (commit 539eaa2) por si hace falta el script de copia.
