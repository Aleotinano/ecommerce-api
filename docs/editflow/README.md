# EditFlow

El software de gestión para la agencia de video vive en su propio repo:
`Aleotinano/Editflow-Api`, que desde 2026-10-04 es un monorepo con la API (`apps/api`), la web
(`apps/web`) y los contratos compartidos (`packages/shared`). Su documentación —revisión del
estado, arquitectura, dominio, qué se reutiliza de Cori y el plan por fases— está en su `docs/`.

Esta carpeta tenía un kit para arrancarlo desde cero; quedó superado al revisar el código que
ya existía. Sigue en el historial de git (commit 539eaa2) por si hace falta el script de copia.
